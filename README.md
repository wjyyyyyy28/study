# 研途 · 考研学习打卡

一款可在手机浏览器中使用、并安装到桌面的考研学习打卡应用。

![研途手机界面](./preview-today.png)

## 下载

- 固定网页：<https://wjyyyyyy28.github.io/study/>
- Android APK：[下载安装包](./downloads/Yantu-1.0.0.apk)
- iPhone 安装描述文件：[下载 Web Clip](./downloads/yantu-ios.mobileconfig)

## 功能

- 点击开始后自动计时，可暂停、继续或结束打卡
- 息屏、切换应用或重新打开页面后，按真实开始时间补算
- 记录学习科目、时长、状态和当天复习内容
- 暂停或结束打卡时可清零本次计时，并在清零前进行二次确认
- 选择考研年份，查看考试倒计时
- 设置目标院校、目标总分和各科目标分，并获得院校专属鼓励语
- 每次进入应用时显示每日鼓励页
- 学习日历、连续打卡、周学习时长和科目分布
- 设置每日学习目标和个人昵称
- 本地保存学习数据，支持导出与恢复备份
- 支持离线访问，可安装到手机桌面

## 运行

需要 Node.js 18 或更高版本。

```powershell
npm start
```

然后打开 `http://localhost:4173`。

如果希望在同一 Wi-Fi 下的手机上打开，可访问 `http://电脑的局域网IP:4173`。要使用完整的离线安装体验，建议将本目录部署到支持 HTTPS 的静态网站服务。

在“我的 → 安装到手机桌面”中可以将应用添加到桌面。手机和电脑处于同一 Wi-Fi 时，也可以在手机浏览器中直接打开局域网地址；如果没有反应，请确认电脑防火墙允许 Node.js 接收局域网连接。

## 在 iPhone 上安装

1. 使用 Safari 打开部署后的 HTTPS 网址。
2. 点击底部“分享”按钮。
3. 选择“添加到主屏幕”，再点击“添加”。

安装后会像普通 App 一样从桌面独立打开。PWA 不需要经过 App Store，但 iOS 不允许直接安装第三方 `.ipa` 文件；如需 App Store 或 TestFlight 安装包，必须使用 Apple Developer 账号完成签名。

## 数据说明

学习记录保存在当前浏览器本地，不会上传到任何服务器。清除浏览器数据或更换设备前，请在“我的 → 数据与备份”中导出备份。
